# 唐朝官职头衔 Wiki

唐高祖武德元年至唐哀帝天祐四年（618—907），含武后临朝及武周阶段。以官署、职类和制度变化为主线的可核查编纂稿。

本编含 **1,600 条官名、等第或头衔记录**、**78 项重要沿革节点**，以及 **53 份古籍分卷工作摘录**。条目含左右、州县等第、时期分行及非职事身份，不代表唐代同时有这些种官职。

先读[凡例](00-凡例与考证方法.md)与[头衔结构](01-官职头衔的基本结构.md)，再按下列分类进入。所有表格提供品位或性质、定员、职掌、时期和依据；明确的变动尽量标公元年与年号，未考定处不补造年份。

## 使用与可信度

解压后保持文件结构，用支持标准 Markdown 相对链接的阅读器打开 README.md。官名索引使用表行锚点；若阅读器不支持表内 HTML 锚点，链接仍可打开目标页，再搜索官名。

核心依据为《唐六典》、两《唐书》职官志及部分《通典》《唐会要》、食货志。现代研究区分全文选读、摘要和书目核验，未亲读的专著不伪造页码。**本编是系统编纂稿；不能保证穷尽所有临时使职、地方自署官和每一年的变动。**详见范围与待考页。
