# 中央文官总览

[首页](README.md) · [官名索引](04-官名总索引.md) · [年代](02-制度沿革年代总表.md) · [史料](91-史料分卷导航.md)

“三省六部九寺五监”适合作为初步记忆框架，却没有包括宫廷全部六省、御史台、东宫、馆学、使职及全部时期的变化。六部与九寺诸监在政令、审查与具体事务上分工，不能直接画成“每个寺都归某部指挥”的现代部委树。

| 系统 | 主要构成 | 主要性质 |
| --- | --- | --- |
| 中枢决策 | 皇帝、宰相、政事堂／中书门下 | 决策、议政与政令协调 |
| 两省 | 中书、门下 | 草拟、审议、封驳、侍从 |
| 尚书省 | 都省、六部二十四司 | 综合行政政令、分类审核 |
| 御史台 | 台院、殿院、察院 | 监察、弹劾、部分司法审理 |
| 九寺 | 太常、光禄、卫尉、宗正、太仆、大理、鸿胪、司农、太府 | 专门事务；各寺权限有变化 |
| 诸监 | 国子、少府、将作、军器、都水；另见太史系统 | 教育、营造、制作、水利等 |
| 馆学与使职 | 弘文、集贤、翰林、史馆、财政使等 | 学术、诏令、史书与专门委任 |
| 宫廷诸省 | 秘书、殿中、内侍 | 藏书、供御、内廷事务 |

阅读具体年份时，先查[年代总表](02-制度沿革年代总表.md)和该机构页，再查[异名索引](03-历代改名与异名索引.md)。
