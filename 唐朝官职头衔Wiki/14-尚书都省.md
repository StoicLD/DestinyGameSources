# 尚书都省与六部二十四司

都省统摄、审核六部行政。左右丞、左右司分统诸曹；六部尚书、侍郎与二十四司郎中、员外郎构成不同层次。

## 二十四司对照

| 部 | 本司与所属三司 |
| --- | --- |
| 吏部 | 吏部、司封（主爵）、司勋、考功 |
| 户部 | 户部、度支、金部、仓部 |
| 礼部 | 礼部、祠部、膳部、主客 |
| 兵部 | 兵部、职方、驾部、库部 |
| 刑部 | 刑部、都官、比部、司门 |
| 工部 | 工部、屯田、虞部、水部 |

这些名称既可能指六部之一，也可能指部下本司；“吏部郎中”与“司封郎中”均是司层级官。掌财政的度支司与后来判度支使职有历史关联，却不是简单更名关系。[^N046]

补充：仆射改左右丞相，N046系开元元年，J42记“开元元年十二月”；这是713年末农历纪年层的记法问题。本编不把“开元二年714”为唯一已定事实。
