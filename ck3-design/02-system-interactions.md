# 跨模块联动案例

[返回总览](README.md) · [设计总纲](00-framework.md) · [制作与原型](03-production-and-prototype.md)

本页以构造场景解释系统关系，**不是某个固定剧本的必然事件顺序**。表内写“可能”的结果仍取决于角色、法律、资格、资源和实际判定。案例采用现行机制结构，省略具体概率与数值。

## 1. 一次联姻如何改变两代人的战争

前提：玩家控制一个封建家族，当前仍使用多继承人分配；有邻国联姻机会，双方都满足婚姻资格。

| 步骤 | 当下发生什么 | 写给其他系统的后果 |
| --- | --- | --- |
| 选择联姻对象 | 获得合资格的联盟关系 | [03 婚姻](modules/03-marriage-family.md) → [06 外交](modules/06-diplomacy.md) |
| 借助盟友参与战争 | 战斗改变军费与兵力，盟友是否响应仍需判断 | [06 外交](modules/06-diplomacy.md) → [18 战争](modules/18-war.md)、[14 财政](modules/14-economy.md) |
| 获得新的头衔 | 统治范围增加，但新地产可能需要恢复控制 | [09 头衔](modules/09-titles-claims.md) → [15 地方治理](modules/15-counties.md) |
| 生育并培养子女 | 家族出现更多成员及未来接班选择 | [03 婚姻](modules/03-marriage-family.md) → [02 教育](modules/02-education-lifestyle.md)、[04 宗族](modules/04-dynasty.md) |
| 当前统治者死亡 | 根据继承法分配头衔，更新亲属宣称与人物关系 | [05 继承](modules/05-succession.md) → [09 头衔](modules/09-titles-claims.md)、[06 外交](modules/06-diplomacy.md) |
| 新继承人上位 | 个人能力、可控资源和封臣态度与上一代不同 | [01 人物](modules/01-character.md) → [10 派系](modules/10-subjects-factions.md) |
| 亲属或封臣争权 | 利用宣称、派系或外交寻找新的分配方案 | [10 派系](modules/10-subjects-factions.md) → 下一场政治竞争 |

不能从“联姻”直接推导出“吞并邻国”。真正的链条需要持续验证婚姻归属、继承资格与各方存活情况。[^1]

设计点：短期正确的联姻和扩张可能让下一代面对更复杂的继承问题。深度来自各系统共享真实结果，不需要人为添加“扩张达到五次就触发兄弟反目”。

## 2. 一条秘密如何替代一场内战

前提：某强力封臣是反对派系的关键成员，玩家能够调查其宫廷，并可能得到可用于勒索的秘密。

1. [内阁](modules/12-council-court.md)的间谍工作发现秘密。
2. [信仰规范](modules/17-faith.md)与行为性质决定秘密的社会严重程度。
3. 玩家在[秘密系统](modules/07-secrets-hooks-prisoners.md)中选择公开，或尝试勒索。
4. 如果获得适用的牵制，可能用来影响具体互动，或触发其被动政治约束。
5. 关键封臣从反对者集合中移出或受到约束后，[派系](modules/10-subjects-factions.md)重新计算实力。
6. 内战威胁降低，但对方未必喜欢玩家，其亲族关系和未来机会仍可能带来冲突。[^2]

设计点：信息通过制度转换为实际权力，最后影响军事风险。若牵制只提供一笔金币，这条跨系统路径就不成立。

验证重点：秘密的知情范围、牵制适用范围、派系成员限制和集体力量计算必须一致。否则玩家会看到“已被控制的人仍能按旧规则反叛”的矛盾。

## 3. 一次朝圣如何制造宫廷权力问题

前提：统治者将前往领国外地点，路上有风险，指定摄政并非完全无私。

| 选择 | 直接回报或代价 | 连锁影响 |
| --- | --- | --- |
| 更长但安全的路线 | 旅行时间增加，某些危险降低 | 离开国内权力中心更久 |
| 较大随行队伍 | 安全或活动表现改善，但有额外成本 | 部分岗位人物也离开原位置 |
| 完成宗教活动 | 获取宗教成长与事件结果 | 回国后的宗教互动机会变化 |
| 摄政持续治理 | 代理人完成任务并可能积累自身力量 | 回国时是否能顺利结束共享权力需要再判断 |
| 途中伤病或死亡 | 原计划被中断 | 继承、岗位与家族状态重算 |

上述联系由[旅行](modules/20-activities-travel.md)、[共享权力](modules/13-power-sharing.md)、[人物健康](modules/01-character.md)和[继承](modules/05-succession.md)共同形成。[^3]

设计点：空间移动改变谁在场、谁掌权、谁能接近谁。旅行因此有政治成本，而不只是在地图上播放一段行走动画。

## 4. 行政家族为何能在失去职位后继续游戏

前提：在可玩行政制下经营一个拥有宅邸的家族，家族成员在某省任职。

| 权力或资产 | 归属问题 | 职位变化后的处理方向 |
| --- | --- | --- |
| 家族宅邸 | 家族的持久资产 | 不应简单随总督职位一并送给下一位任职者 |
| 总督职位 | 制度任命产生的公共权力 | 按候选与任命体系转交 |
| 职位关联军队 | 与头衔关联的军力 | 随对应职位／头衔规则改变控制 |
| 私人关系与家族实力 | 由人物及家族积累 | 继续用于争取未来任命 |
| 公款与私人金币 | 具有不同使用规则 | 避免把公共资源和个人财产混为一谈 |

具体继承仍须看对应制度；这里展示的是[行政制](modules/26-administrative.md)中公职与私产分离的设计意义。[^4]

设计点：不必让玩家每次失去政治竞争就彻底失败。保留合适的长期资产，可以使失败成为新的发展阶段，并增加故事变化。

## 5. 灾害如何影响帝国政治和远方地区

前提：启用 All Under Heaven，处在中国王朝循环与相关丝路局势中。

灾害影响地方建设、控制、人物与统治评价；中央和地方通过[大工程与财政](modules/14-economy.md)投入恢复。治理选择以及其他政治事件共同影响[王朝循环](modules/29-china.md)的推进；进入某些宏观阶段后，又会改变[丝路局势](modules/32-situations.md)和更远地区的环境。[^5]

这不是“发生一次洪灾就必然改朝换代”。关键在于局部冲击进入已有指标和阶段条件，与其他行为一起积累，最终才可能改变宏观状态。

设计点：不同尺度不应彼此割裂。地方问题若只扣一个伯爵的收入，就难以成为帝国治理体验；但若每次小灾害都强制触发全国崩溃，因果比例又会失真。

## 6. 哪些联系必须共享真实状态

| 变化 | 必须重新判断的系统 | 常见设计或实现错误 |
| --- | --- | --- |
| 人物死亡 | 继承、婚姻、联盟、内阁、计谋、活动 | 死人继续担任参与者或保留不再成立的支持 |
| 头衔转移 | 直接收益、臣属、首都、资格、战争目标 | 地图已变色，税收和上下级仍指向旧人 |
| 信仰转换 | 罪行、婚姻、宗教关系、战争资格 | 新规则下仍按旧教法进行同一互动 |
| 婚姻改变 | 家族归属预期、联盟、亲属评价 | 将人物婚姻与统治者联盟错误当成一条关系 |
| 失去职位 | 任务、薪俸、公共军力、候选资格 | 家族资产与国家资产一起被错误清除 |
| 地方控制下降 | 收入、征召、腐败和治理任务 | 只显示状态，不改变经营结果 |
| 派系成员变化 | 集体力量、进度与行动可能性 | 阈值使用过期兵力或已退出成员 |
| 计谋目标失效 | 进度、同谋、资源和后续通知 | 无效计谋仍执行并修改无关目标 |
| 局势阶段变化 | 参与者效果、可用互动和关联地区 | 只换阶段标题，规则未同步改变 |
| DLC 或政体变化 | 内容资格、替代机制和持久资产 | 使用付费系统的存续前提却不提供替代规则 |

这张表是面向自己的实现建议，不是对 CK3 内部更新顺序的披露。具体程序结构与验证方法见[工业化制作](03-production-and-prototype.md)。
