# Crusader Kings III 游戏设计拆解

CK3 最值得学习的设计，是让**人物的私人动机、制度的权力分配和跨世代的家族目标持续发生冲突**。婚姻、战争、宗教、封臣、事件分别提供行动方式；继承、关系和制度把行动结果重新接回世界。

这套文档按设计职责拆成 **33 个模块**，覆盖 PC 本体、免费更新及已发布的主要玩法 DLC。每篇都包含核心体验、子机制、关键取舍、系统联系和可以缩小实现的学习实验。它是设计层的全景拆解，不是逐条抄录全部事件、特质、建筑和数值的百科，也不代表 Paradox 内部代码架构。

## 建议阅读顺序

第一次读：总纲 → 01 → 03 → 05 → 09 → 10 → 18 → 联动案例。先看懂人物、权利和权力重组，再补数值与内容。

准备做自己的游戏：总纲 → 01 → 07 → 10 → 22 → 制作与原型路线。先验证小规模人物政治是否成立。

比较不同制度：09 → 10 → 14 → 25，再选择 26—31。重点观察同一个“获得权力”的目标，如何由不同制度提供不同路径。

所有模块都有返回本页、返回总纲、关联模块、反向索引和来源索引的链接。关联模块解释“还应看什么”，反向索引列出“哪些文档引用本篇”。模块之间的链接使用相对路径，整套文件搬到其他目录仍可阅读。
