# 17 信仰、教义与宗教权力

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

在一套社会规范中取得认可，并利用宗教权威、转信或改革改变自己的行动空间。遵循或挑战规范 → 积累宗教资源 → 获得支持、权利或新的信仰 → 承担群体关系变化。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 宗教与具体信仰 | 大宗教之下存在具体教派和规则组合 | 共同背景不代表完全相同的政治关系 |
| 核心教义 Tenets | 决定鲜明玩法倾向、特殊能力和价值偏好 | 选择哪种行为得到制度性奖励 |
| 教法 Doctrines | 定义婚姻、性别、教士、罪行等具体规则 | 改变规范会影响多个既有系统 |
| 美德与罪恶 | 同一人格在不同信仰下受到不同评价 | 人格没有脱离制度的统一社会价值 |
| 宗教领袖 | 特定教法下的资源、宣称、惩处和权威来源 | 争取宗教支持，还是建立更独立的统治 |
| 圣地 | 地理位置与信仰力量、改革资格等相连 | 将宗教目标变成地图上的战略目标 |
| 热忱 Fervor | 信仰群体的状态，关联改宗、异端和宗教竞争 | 群体宗教力量不同于个人虔诚余额 |
| 转信、创建与改革 | 满足条件后改变人物或群体的宗教规则 | 获得制度优势，同时可能失去盟友与稳定 |
| 圣战与大圣战 | 按信仰、时代及其他条件开放战争形式 | 宗教关系决定谁可攻击、谁可能参与 |

本文描述 1.19 基线。By God Alone 预告的动态圣地、可玩神权和新基督教局势不纳入现行规则；不能将其提前用于本模块推演。[^2]

## 关键决策与设计判断

宗教最可借鉴的部分，是把“规范”做成参与实际结算的规则。例如某项行为从被鄙视变为合法，会改变秘密价值、惩罚资格、婚姻空间与人际评价，而非只换一种界面颜色。

创建信仰也是一种规则构筑，但应有政治落地成本。否则玩家只需拼出数值最好的组合，不必应对社会中的反对与传播困难。

## 借鉴与最小验证

设计两个虚构信仰，只在婚姻、某项罪行和军事倾向上不同。执行一次转信，让既有秘密、盟友态度和可用行动重新判断。

检查系统是否能解释哪些变化立即生效、哪些需地方转化。不要把教法改变当成全世界自动同意。
