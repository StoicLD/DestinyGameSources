# 28 游牧与草原

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

以牧群和移动组织维持力量，利用肥力变化、迁徙、战争和臣属关系扩大优势。利用牧场 → 增加牧群 → 形成军力与地位 → 面对资源环境变化 → 迁徙、索取或征服。可玩游牧体系来自 Khans of the Steppe。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 牧群 Herd | 兼具财富、政治地位与兵力来源的作用 | 留作增长基础，还是转化为军事和政治能力 |
| 草原肥力 | 地区可承载和再生的资源条件 | 当前收益与未来牧场条件 |
| 草原季节局势 | 多年尺度改变地区条件，不是普通年度冬季的同义词 | 预判、等待、迁徙或趁机行动 |
| 游牧首都 | 可移动的持久资产 | 世界位置会变，队伍与核心积累继续存在 |
| 迁徙 | 在资格和距离允许下转移，可能通过同意或战争完成 | 转移资源基础，而非只不断占满地图 |
| 忽里勒台与服从 | 要员的服从对组织与继承重要 | 强化个人统治还是协调精英 |
| 朝贡与统御 | 通过较松散关系获取资源和影响 | 广泛索取与深度控制 |
| 骑兵与补员 | 牧群和特有组织方式影响军力形成 | 军事损失会反过来影响经济基础 |
| 联合与特殊崛起 | 结盟、草原联合及大汗相关内容提供不同规模的政治目标 | 从生存组织转向大规模征服 |

游牧继承不能仅套用封建分割；服从、空缺职位和特定季节等可影响接班结果。牧人 Herder 则是不同的非王朝政体角色。[^1][^2]

## 关键决策与设计判断

固定地产与可移动产能会制造完全不同的地图价值。迁徙不是失败撤退的附属动作，而可以是维持经济的正常行为。

这种系统特别依赖预警。如果环境改变只能事后发现，玩家容易认为资源被任意没收。季节信息、肥力趋势和迁移范围必须共同可见。

## 借鉴与最小验证

做三片牧场、一个牧群数值和可预见的两阶段环境变化。玩家需要决定何时迁移、是否向邻居付出代价。

验证不发动战争也能有有意义的行动；再加入一位不服从的要员，观察资源危机是否放大继承风险。
