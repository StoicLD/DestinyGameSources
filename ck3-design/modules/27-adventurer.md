# 27 无地冒险者

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

带着营地与追随者在既有政治世界中谋生，把技能、名望和关系逐步换成更大的机会。寻找契约 → 旅行并解决雇主问题 → 获取金币、行粮和名望 → 升级营地与队伍 → 继续冒险或争取落地。可玩身份来自 Roads to Power。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 营地与方向 | 作为可移动资产载体，并通过建筑与营地方向形成专长 | 接哪类业务、带什么人 |
| 契约 | 为有地统治者处理事务，不同任务使用不同能力 | 报酬、距离、风险和擅长领域 |
| 行粮 Provisions | 迁移消耗受队伍与路线影响 | 更强军力也可能增加移动成本 |
| 追随者与军队 | 依赖常备兵、骑士和营地角色，而非普通地产征召 | 人才需求与补员方式 |
| 赞助者名录 | 既有雇主与关系对象提供请求机会 | 维护长期客户，或开拓新地区 |
| 专属生活方式 | 与有地统治者存在不同效果和用途 | 角色能力适应新的谋生方式 |
| 接班与落地 | 营地有自己的继承安排；可以改变为有地生活 | 长期游历与建立稳定领地 |
| 身份转换 | 某些情况下失地后可转为冒险者 | 失败可以开启另一种循环 |

当前冒险者兵力维护与补充规则不同于一般领主，不能直接复制封建军队经济模型。未来开发日志中计划的改动也不等于当前已生效。[^1]

## 关键决策与设计判断

它复用了同一个人物世界，却更换主要资产、收入来源和空间行为。其他领主的政治问题成为冒险者的工作，这比在大地图旁增加孤立任务模式更有整体性。

需要关注规模成长后的张力：如果队伍越来越强而缺少相称负担，契约就可能变成重复领奖。这个问题应通过当前版本体验和数据验证，不能仅凭宣传判断已经解决。

## 借鉴与最小验证

做一支 3 人队伍、2 个雇主、3 类契约和一张小路线图。让一次成功契约解锁后续请求，但频繁索取降低雇主关系。

验收看雇主是否成为玩家记得的人，以及迁移是否有实际选择。原型末尾提供“接受一个小职位／继续游历”作为不同发展方向。
