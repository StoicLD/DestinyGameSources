# 18 战争目标与和平

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

用军事力量兑现明确的政治目标。选择战争理由 → 判断参战者与成本 → 动员与争夺目标 → 达成胜利、白和或认输 → 接受制度预设的政治结果。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 宣战资格 | 宣称、法理、征服、宗教、臣服或特殊政体理由等 | 先获得资格，还是使用代价不同的另一条路径 |
| 战争理由 Casus belli | 规定目标与不同结果下的收益、损失 | 战前就判断“胜利究竟给谁什么” |
| 为他人宣称开战 | 胜利可能安装另一名人物成为统治者 | 其亲属、等级和制度关系决定自己得到什么 |
| 战争分数 | 目标占领、战斗、重要俘虏及目标控制时间等推动结算 | 追击主力还是夺取目标、首都和关键人物 |
| 盟友与参战贡献 | 盟友是否参战、贡献多少影响过程和收益 | 能调用的支持不等于完全可控的军队 |
| 和平与停战 | 胜利、白和、投降按战争理由结算，并产生后续约束 | 趁早兑现有限成果，还是继续冒险 |
| 内战与大圣战 | 参与者、目标和胜后分配具有特殊规则 | 同样的军事操作可能服务截然不同的政治结果 |
| 战争失效 | 关键人物、目标或资格变化可能使原有战争基础消失 | 政治行动能改变战争，而不只靠战场获胜 |

军队占领某地不等于和平后永久获得该地。还必须看战争目标与结算规则。[^1]

## 关键决策与设计判断

将胜利结果提前确定，能够给战斗提供政治意义，并阻止每场小战争自然变成无限兼并。游戏不需要复杂的任意和平拼单，也可以形成丰富战争目标。

战俘和继承人让角色系统直接接入战争。俘获关键人物改变和平可能性，是比单纯累积伤亡更有特色的反馈。

## 借鉴与最小验证

做“夺取一个地区”和“拥立另一名统治者”两种战争。战斗可以先用简化计算，但胜利必须产生不同的权力变化。

验证玩家在宣战前能预测结果，在获胜后能解释谁得地、谁成为封臣、哪些关系结束。优先验证政治结算，再完善战斗动画。
