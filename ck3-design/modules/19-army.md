# 19 军队、战斗与后勤

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

建立适合目标与地理条件的军力，并在有限补给和预算下取得战场优势。组建 → 动员 → 行军与分兵 → 战斗或围城 → 补充和解散。人物能力、地产建设和制度都参与其中。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 征召兵与常备兵 | 征召兵提供基础规模，常备兵有兵种特性与克制 | 数量、质量、维护费和敌军组成 |
| 骑士与指挥官 | 骑士以人物参战；指挥官以军事能力和特质影响军队 | 战斗收益与重要人物受伤、死亡、被俘风险 |
| 军事建设与驻扎 | 部分地产和建筑增强驻扎常备兵 | 经济布局同时塑造军事专精 |
| 地形与优势 | 河流、山地、登陆、指挥与战斗宽度等改变有效战力 | 更大军队不必然在任何战场占优 |
| 集结与移动 | 集结时间、分兵、移动锁定和渡海成本限制调动 | 战略部署不能完全瞬间重来 |
| 补给与损耗 | 地方承载力、补给状态、围城与敌境行动影响损耗 | 集中作战与分散补给 |
| 围城 | 兵力、要塞和攻城器械影响占领速度 | 追求野战胜利还是快速兑现战争目标 |
| 雇佣军与骑士团 | 提供依条件使用的外部军力 | 支付额外资源处理短期缺口 |
| 劫掠与决斗 | 劫掠带回资源；决斗以少量人物解决具体冲突 | 分别提供不必全面战争的收益或争端路径 |
| 骑士荣誉 Accolades | 以人物和统治成就建立持续军事特色 | 维护专精而不是只雇佣最高勇武人物 |

1.19 已重做骑士荣誉的属性与接替方式，不能继续把旧版“主／副属性＋手动继任人”作为当前规则。[^2]

## 关键决策与设计判断

战斗应让玩家从结果中理解损失来自哪里：兵种、地形、指挥、补给还是人物风险。展示一个“军队质量”标签有助扫读，却不能替代对关键因素的解释。

这套战争的战略深度不依赖直接操控每一个士兵。个人开发者可以先用军队级结算验证地理与政治的相互作用。

## 借鉴与最小验证

三种兵、两类地形、一名指挥官、一条补给轨。用同一对军队在不同地形和补给条件下战斗，结果必须有可解释的差异。

只做一次围城和一次关键人物被俘，检验它们是否改变[战争目标](18-war.md)的推进。不要先开发复杂实时战术控制。
