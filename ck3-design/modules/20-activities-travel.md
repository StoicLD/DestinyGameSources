# 20 活动与旅行

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

投入时间、空间移动和预算，让人物相聚，并利用聚会实现私人或政治目的。选择活动 → 确定地点、预算、参与者和意图 → 安排旅行 → 在阶段事件中选择 → 带着关系与资源变化返回。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 宴会 | 提供社交、关系与减压等机会 | 邀请谁、是否接受他人的邀请 |
| 狩猎 | 结合地点、成功机会、人物能力与风险 | 声望和成长与危险程度 |
| 朝圣 | 以旅行和事件取得宗教成长 | 路途、费用和离开宫廷的代价 |
| 盛大巡游 | 探访臣属，以不同方式获取政治或经济成果 | 展示权威、建立关系或获取资源 |
| 比武大会 | 多项目竞赛、参与者能力、奖品和活动事件 | 个人参赛、赞助与人才发现 |
| 盛大婚礼 | 将婚盟扩展成参与者共同经历的大事件 | 关系收益与高昂准备成本 |
| 其他专门活动 | 葬礼、大学、加冕、漫游、科举等使用相关框架 | 框架共通，目标与资格不同 |
| 活动意图 | 不同人物可追求不同目标 | 表面庆典可能也是拉拢、恋爱或伤害机会 |
| 路线、随行与危险 | 地形、治安、疫病和旅行选项改变过程 | 最短路线、安全路线与兴趣点路线 |
| 旅行的世界后果 | 离境可能触发摄政，某些计谋进度受位置影响 | 出行不是无成本切换场景 |

旅行与摄政框架来自免费更新；盛大活动等和各专门活动的可用性需分别核对 DLC。[^2]

## 关键决策与设计判断

活动将原本分散的人物暂时放入共同情境，提高关系系统产生交互的密度。真正值得借鉴的不是大量庆典名称，而是“共同场所＋不同意图＋持续后果”。

风险在于重复举办活动变成收取固定加成。需要让参加者、地点与当前政治目的对选择产生实质影响。

## 借鉴与最小验证

做一场有 4 名宾客的宴会，玩家从安抚封臣和拉拢同谋两个意图中选一个。途中只设一条安全绕路与一条危险近路。

验收看同一场宴会是否能因宾客与意图不同而改变政治关系。若只有一个“活动成功度”决定全部收益，先增加人物之间的真实交互。
