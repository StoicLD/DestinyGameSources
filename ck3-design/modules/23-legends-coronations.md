# 23 传奇、加冕与誓言

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

将统治成就转化为被传播、被见证和被期待的政治叙事。传奇强调“让别人相信自己的伟业”；加冕强调“让别人认可自己的统治，并公开承诺未来”。二者共享合法性和活动系统，但拥有不同循环。[^1][^2]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 传奇种子 | 特定经历、身份或成就提供传奇起点 | 选择哪段经历作为家族的公共叙事 |
| 传奇传播 | 投入资源和人物推动影响范围 | 支出当前资源换取政治和家族收益 |
| 传奇质量与完成 | 按传奇类型与发展获得相关奖励、决议或建筑机会 | 继续投资，还是及时兑现 |
| 编年史与宣传人物 | 宫廷人员和活动帮助维持叙事 | 普通职位进入更长期的政治目标 |
| 加冕仪式 | 邀请封臣，安排仪式和庆典；参与者各有立场 | 借典礼凝聚支持，承受反对者干扰 |
| 加冕法律与物件 | 仪式与宗教资格、头衔和冠冕／礼器相连 | 仪式成为继位过程中的实际任务 |
| 誓言 | 宣示统治目标，并通过后续行为履行 | 选择适合当前局势且能实现的承诺 |
| 仪式结果 | 加冕表现与支持／反对关系影响收益和后续 | 不能把加冕简单当成花钱获得固定加成 |

传奇、加冕并不等于基础合法性；基础合法性免费，传奇与加冕的扩展内容分别关联 Legends of the Dead 和 Coronations。[^1][^2]

## 关键决策与设计判断

传奇把“已经完成的事”再加工成传播与投资目标；誓言把“打算完成的事”变成有社会后果的公开任务。它们分别延长了成就的后效与未来目标的约束。

风险是奖励覆盖太多系统后变成必做功课。原型应检查玩家是否有合理的不投资选择，以及宣传收益能否与真实统治能力区分。

## 借鉴与最小验证

设计一次加冕和两条誓言：保护领地、改善民生。誓言必须读取战争或建设中真实发生的行为，不设置脱离世界的额外刷分按钮。

完成后验证承诺、执行与结果之间能否被玩家复述。传奇可随后以“一项成就＋两名传播者＋一个传播范围”加入。
