# 25 封建、部落与氏族

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

三种本体政体共享人物、头衔和家族系统，但以不同方式生产资源、安排臣属和分配继承。研究政体时，应优先比较其循环，不只比较加成大小。[^1]

## 三种循环

| 政体 | 核心循环 | 主要约束 |
| --- | --- | --- |
| 封建 Feudal | 经营直辖地产 → 谈判封臣契约 → 稳定财政与军力 → 扩张和安排继承 | 土地容量、契约权利、强力封臣与继承分割 |
| 部落 Tribal | 争取名望、劫掠和征服 → 维持追随者与兵力 → 再扩大地位 | 革新时代、地产建设与继承制度限制 |
| 氏族 Clan | 组织亲族与联姻 → 安排税区税吏 → 调整团结与权力 → 经营扩张和接班 | 家族团结、权势封臣联盟期待与征税组织 |

封建强调金币和土地的持续经营；部落能够用威望支撑部分军事与建设需求；现行氏族税收应看税区、税吏和税令，不应继续用首发版“只由封臣好感决定收入”概括。[^1][^2]

## 子机制与设计作用

| 子机制 | 核心内容 | 可借鉴的差异 |
| --- | --- | --- |
| 封建契约 | 交换税赋、兵役和特权 | 同样是封臣，也能存在不同合同 |
| 部落权威与名望 | 政治地位影响组织能力 | 社会资本成为生产与军事资源 |
| 劫掠 | 不必正式夺地即可获取资源并撤回 | 增长有“拿走资源”的路线 |
| 制度转型 | 满足条件后从部落进入封建或氏族等体系 | 原本强势的资产结构需要重新适应 |
| 氏族税区 | 将多个纳税者交给税吏处理 | 财政依赖中间管理者 |
| 家族团结 | 亲族之间的统一／分裂行为影响共同状态与继承 | 日常人际行动能改变制度结果 |
| 维齐尔 | 提供治理帮助，也积累独立权力 | 效率收益与代理成本同时存在 |
| 诺斯扩展内容 | Northern Lords 的瓦兰吉冒险、特色传承、祭典和决议 | 在既有规则上组合迁居、征服与文化目标 |

瓦兰吉冒险是一种特定地区与资格下的迁居征服玩法，不等于 Roads to Power 的一般无地营地生活。[^3]

## 设计判断与最小验证

先用同一张小地图实现封建和部落两套收入／军事规则，并让两者各有一个合理优势。再加入氏族税吏，不必同时增加新地图。

验证同一块地、同一名人才是否因政体不同而具有不同价值。若玩家在三种政体下仍执行完全相同的操作顺序，说明差异停留在数值皮肤。
