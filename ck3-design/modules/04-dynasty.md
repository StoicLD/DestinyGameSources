# 04 宗族、家族与传承

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

在人物会死亡、疆域会分裂的世界里，为玩家提供跨世代的共同身份与积累。宗族 Dynasty 包含多个家族／支系 House；成员争取地位 → 提升宗族声誉 → 解锁传承 → 让未来成员受益。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 宗族与家族 | 长期血统共同体及其内部支系 | 同宗并不意味着归同一政治指挥 |
| 家主与宗族长 | 分别拥有不同的家族互动权限 | 控制家族领导权本身具有价值 |
| 宗族威望 Renown | 由家族成员地位等来源积累，用于传承和强力互动 | 投资永久收益，还是处理眼前接班问题 |
| 宗族传承 | 对宗族成员生效的长期路线 | 军事、婚姻、教育、治理等长期专精 |
| 支系与成员外放 | 建立分支、让成员在外获得地位 | 扩大宗族影响与保持直属控制之间存在张力 |
| 家族关系、恩怨 | 成员行为能累积成家族间关系；事件包扩充冲突故事 | 一个人的行为可能影响尚未出生的后代 |
| 收养与废黜继承资格 | 在满足制度条件时改变成员归属或继承资格 | 家族存续、政治正当性与资源成本 |

同宗统治者若处在同宗上级之下，并不能简单叠加所有统治地位带来的 Renown；因此“把所有亲戚都封在自己下面”不等于最大化宗族收益。家族关系框架在 1.18 免费更新中进一步扩充。[^1][^2]

## 关键决策与设计判断

人物资源、家族共享资源和公共权力必须区分。宗族长能使用公共积累，但其他成员未必赞同其用途，这天然产生内部政治。

这一系统提供的是同一场战役中的跨代成长，不能直接类比为每次重开都保留的 roguelite 局外升级。将“个人死亡”和“玩家长期进度”分离，是最可复用的结构。

## 借鉴与最小验证

做一个共同家族资源池和两条永久升级。安排一位亲属成为独立小领主：他能给家族带来价值，却不再受玩家直接控制。

验证玩家是否愿意接受“领土没有增加，但家族目标得到推进”。若所有评价仍只依赖疆域，就需要给家族目标更明确的反馈。
