# 01 人物、特质与压力

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

让玩家以一个有能力边界、性格倾向和有限寿命的人行动。人物既是操作者，也是继承、关系、疾病和事件的承载对象。核心循环是：识别自己的长处与性格 → 选择行动 → 承担资源、压力和人际后果 → 调整策略。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 五类技能与勇武 | 外交、军事、管理、谋略、学识影响不同领域；勇武偏向个人战斗 | 亲自解决、任用专家，还是改变问题的解决路径 |
| 人格特质 | 改变能力、互动、AI 倾向及部分事件选项 | 同一个方案对不同性格人物的代价不同 |
| 压力与精神崩溃 | 违背性格、亲近者死亡等可增加压力；越过阶段阈值触发风险 | 短期政治收益是否值得长期精神成本 |
| 应对机制 | 部分特质和行为提供减压，同时可能引入副作用 | 支付时间、金钱或健康代价管理压力 |
| 健康、伤病与衰老 | 健康影响死亡风险，死亡触发继承；1.19 加入逐步恶化的老年特质 | 当下参与危险行动，还是延长准备接班的时间 |
| 外貌与身份呈现 | 年龄、遗传、伤病、服饰和头衔帮助识别人及其状态 | 形成记忆、地位感与角色认同 |

规则依据为 Attributes、Character 与 1.19 更新。健康不是普通动作游戏中可直接等同使用的血条；压力也不是简单的“邪恶值”。[^1][^2]

## 关键决策与设计判断

一位公正的统治者可能仍选择不公正的行为，但要承受性格冲突带来的代价。这比完全禁止行动更能保留策略空间：人物塑造决策成本，玩家仍决定是否支付。

角色的能力、意愿和社会评价应分开。一个人擅长谋略，不代表必然愿意谋杀；一个人害怕领主，也不意味着喜欢领主。将这些合并成一个“忠诚值”会损失大量人物政治。

## 借鉴与最小验证

原型只做 3 种人格、2 类能力、1 条压力轨、6 个事件。让同一个“公开罪行／收钱隐瞒”选择在不同人格下产生不同代价。

观察玩家能否说出“这件事值得做，但不适合我当前这个人”。若永远点击同一个选项，先检查奖励是否压倒人格成本；若几乎不能行动，则约束过重。不要先复制数百个特质。
