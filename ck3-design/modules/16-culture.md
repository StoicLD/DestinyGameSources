# 16 文化、传统与革新

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

经营一个群体的习惯、技术与彼此接受程度，并在条件允许时改变这套规则。扩大或调整文化基础 → 选择革新与传统 → 改变成员的行动能力 → 处理同化、共存与融合。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 文化支柱 | 传承、语言、美学、军事惯例和精神等共同定义文化 | 身份、视觉与规则形成可辨认组合 |
| 传统 Traditions | 授予能力、奖励某些行为或改变限制 | 选择符合环境和长期玩法的传统 |
| 文化领袖 | 影响文化革新关注点与改革 | 政治统治范围不自动等于文化领导权 |
| 文化接受度 | 两个文化之间的相处程度 | 扩张后同化或培养共存 |
| 语言 | 学习语言影响跨文化互动 | 投入个人时间换取群体沟通优势 |
| 改革、分化与融合 | 改变既有文化或产生新文化；后两者有 DLC 条件 | 灵活构筑与费用、时间和资格限制 |
| 革新 Innovations | 军事、民政、地区与文化技术等，按时代和条件开放 | 即时军事需要与长期制度、经济发展 |
| 传播与研究条件 | 文化发展水平、关注点和接触影响进度 | 地域扩张可能改变文化整体发展结构 |

All Under Heaven 增加丝绸之路革新传播；它与普通文化研究有关，但有额外地区条件。当前资料中的革新关注加成也不能一概照搬早期仅按学识概括的公式。[^2]

## 关键决策与设计判断

文化把角色构筑放大到群体层。玩家改变的不是一名角色的装备，而是许多人未来能做什么。这使“制定规则”成为长期玩法。

同化不应天然优于共存。如果所有异文化只产生惩罚，最优解就会退化成统一染色；接受度、语言和融合提供了更多关系路径。

## 借鉴与最小验证

只做两个文化、各三项传统和一项可传播技术。提供同化与提高接受度两种政策，再加入一个可组合的新传统。

验证两种路线能否支持不同经营策略。先证明规则组合有区别，再增加文化名单；不要先制作几十个几乎相同的文化。
