# 07 秘密、牵制与囚犯

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

把不对称信息和人物处境转化为可使用的政治资源。发现秘密 → 判断公开或勒索的收益 → 获得牵制 → 在合适的互动中使用；俘虏则通过赎金、释放条件和惩罚提供另一条筹码链。[^1][^2]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 秘密与知情 | 行为可以存在但未公开，特定人物知道它 | 继续保密等待机会，还是立刻公开 |
| 犯罪与被鄙视的行为 | 严重程度取决于信仰等社会规则 | 同一条情报在不同制度下价值不同 |
| 勒索 | 用不公开秘密换取对方让步，失败可能导致曝光 | 直接打击对方，还是保留可重复利用的关系 |
| 弱牵制 | 通常一次使用，为允许使用的互动增加筹码 | 小便利是否值得现在消耗 |
| 强牵制 | 多数适用互动中约束更强，可按冷却复用并具被动限制 | 政治控制与被对方敌视可以并存 |
| 永久牵制 | 特殊来源，可重复使用，但不等同于所有场合的强牵制 | 看清类型，而非仅看持续时间 |
| 囚犯处置 | 释放、赎金、谈判条件、招募或惩罚等 | 金钱、人才、威慑与政治后果相互替代 |

牵制不能用于全部互动，也不是万能服从指令。囚犯的价值还取决于身份及其和交战领袖、继承人的关系。[^1][^2]

## 关键决策与设计判断

最有价值的结构是“事实—知情—公开—社会后果”四层分离。若创建秘密时立刻给全世界加负面好感，就没有真正的信息博弈。

囚犯同样应保留原有身份。他可能是一个差劲骑士，却是敌国继承人；这种价值由关系网络产生，比统一标价更有策略意义。惩罚还可能影响其亲族，给下一轮冲突留下人物动机。

## 借鉴与最小验证

制作三名角色、一个秘密、两套犯罪规则、两种牵制与一个囚犯。让玩家在公开、勒索、赎金和招募之间选择。

检查未知秘密是否泄露到其他角色界面，规则改变后勒索条件是否重新计算，囚犯死亡是否使谈判失效。重点验证关系与信息流，暂不做复杂刑罚演出。
