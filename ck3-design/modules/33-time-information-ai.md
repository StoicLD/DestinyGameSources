# 33 时间、信息、AI 与目标

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

让玩家能够在持续变化的世界中看清问题、决定何时介入，并为长期沙盒设定目标。这里拆的是支撑全部玩法的体验系统：时间控制、信息组织、人物行为可解释性与目标反馈。

## 子机制

| 子机制 | 核心内容 | 设计价值 |
| --- | --- | --- |
| 暂停与变速 | 持续推进的游戏时间允许停下来处理复杂决策 | 减少操作速度对策略理解的遮蔽 |
| 起始书签与规则 | 不同时间、角色、政体与游戏规则改变初始局面 | 用参数组合产生可重复游玩的情境 |
| 提示与数值拆解 | 解释互动资格、接受度、成本和后果 | 让玩家知道可以改变什么 |
| 地图模式与人物检索 | 以不同视角组织同一个世界 | 同一地区可从政治、文化、宗教等角度理解 |
| 总账 Ledger | 1.19 提供战争、人物、家族、地产等可排序信息和收藏 | 帮助发现机会并保持关注 |
| 警报与待办 | 将失去继承、空缺岗位等重要问题及时显露 | 管理注意力，而非要求玩家记住全部状态 |
| AI 人物倾向 | 人格、关系、制度和行动条件影响行为 | 既保持差异，又能从世界事实解释行为 |
| 角色外观与声音 | 年龄、衣饰、徽章、动作和声音提示帮助辨认状态 | 支撑玩家记住大量人物与风险 |
| 成就与自定目标 | 统一领地、延续家族、宗教文化改革等提供不同目标 | 不把所有玩法评价都压成领土大小 |
| 多人互动 | 其他玩家可接替 AI 扮演重要人物 | 社会关系从模型决策扩展到真实协商 |

总账、故事、人物事件名牌、骑士许可等当前功能可从 1.19 更新核对。AI 个性影响计谋参与等行为也有当前机制依据；但本套文档没有据此推断完整 AI 算法或内部决策频率。[^1][^2]

## 关键决策与设计判断

“可解释”不意味着公开所有秘密。应公开规则、已知条件和合理估计，同时保留秘密的知情边界。对策略游戏来说，规则不透明与情报不完整是不同体验。

复杂系统常见的真正瓶颈是注意力。提示应按紧迫性和可操作性组织：即将发生的继承危机比某个遥远陌生人获得头衔更应打断玩家。信息设计从原型第一版就应参与。

## 借鉴与最小验证

给一个 20 人世界做人物列表、关系页、三类警报和可展开的行动原因。AI 只需要少量可解释的权重，不必先模仿完整 CK3。

让未读规则的人处理一场接班危机。记录他是否能找到问题、辨认关键人物并解释方案。若机制成立但用户找不到入口，优先修复信息组织。
