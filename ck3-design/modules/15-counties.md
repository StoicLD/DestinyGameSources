# 15 伯爵领、发展与控制

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

使获得的土地能够稳定服务统治，而不只是改变地图颜色。取得伯爵领 → 恢复控制 → 处理当地文化、信仰与民意 → 改善发展和建设 → 获得持续回报。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 伯爵领与男爵领 | 地方行政与地图单元具有嵌套关系 | 战争、建筑与地方治理使用不同粒度 |
| 控制 Control | 统治权在地方落实的程度，受征服和战乱影响 | 新领地先恢复秩序，还是继续向外扩张 |
| 发展 Development | 地区长期基础条件，影响产出、补给及文化革新 | 集中培养核心，还是分散改善边境 |
| 民众好感 | 地方对直接领主的社会态度 | 贵族关系良好仍可能有基层反抗 |
| 文化与信仰 | 地区身份与统治者可能不同 | 改造当地，任用本地人，或建立兼容制度 |
| 腐败修正 | 低控制、债务等情况下可能出现地方负面状态 | 应急财政会损伤未来治理 |
| 地形、冬季与肥力 | 地形影响发展、建筑和军事；草原肥力另有循环 | 地理条件同时约束经营与战争 |

发展、控制和民意是三个不同维度：一片富庶却不受控制的土地，不能按满额稳定收益估算；贫穷但服从的边境也有战略价值。[^1][^2]

## 关键决策与设计判断

征服后的恢复阶段是经营玩法和战争玩法的接口。它让“打下来”与“经营得好”使用不同能力，也给敌人和内部反对者留下反击窗口。

设计中不宜给所有地区都提供相同最优建设顺序。少量明确的地形差异、军事位置和发展潜力，比大量难以比较的微小加成更有价值。

## 借鉴与最小验证

制作三个地区：富裕且不满、贫穷但稳定、军事要地但低控制。给玩家一名只能执行一项任务的官员。

验证战后玩家是否改变资源分配，并能解释为何没有立刻再次开战。若地方治理只剩“等进度条变满”，加入恢复顺序和用人竞争。
