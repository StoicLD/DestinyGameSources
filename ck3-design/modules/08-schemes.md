# 08 计谋与反制

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

以持续筹备和关系渗透改变某个人或政治局面的状态。选目标 → 选择计谋 → 招募参与者并配置资源 → 分阶段积累 → 决定继续准备或执行 → 承担成功、失败和曝光后果。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 私人计谋 | 如拉拢、交友、恋爱、学习语言等，依具体解锁条件 | 占用时间改善关系或能力 |
| 敌对计谋 | 如谋杀、绑架等，使用隐蔽性与同谋 | 改变人物状态，但可能留下严重政治后果 |
| 政治计谋 | 某些官僚政体内用于升迁、打击或资源争夺 | 以制度内竞争替代直接战争 |
| 成功率与潜力 | 当前成功可能性与可达到的上限分别计算 | 仅等待并不能补足所有准备短板 |
| 阶段与 Advantage | 筹备按阶段推进，积累执行所需的优势 | 提前出手，还是继续积累更好条件 |
| 隐秘性与破绽 | 存在被察觉、削弱乃至失败的风险 | 更多准备时间也意味着暴露窗口 |
| 同谋与诱因 | 同谋的角色、能力和接近目标的程度影响贡献 | 买通关键人物，还是依靠现成关系 |
| 反制重点 | 防范某类威胁，同时支付或接受相应代价 | 防御应有机会成本，不能默认全部拉满 |

这是当前阶段式体系的结构；不能直接沿用首发版“进度满后统一结算”的旧说明。私人计谋与敌对／政治计谋并不完全共享隐蔽规则。[^1]

## 关键决策与设计判断

计谋提供了一种“小势力也能影响大局”的通道，但应依赖接近关键人物的能力。一个目标的内阁、亲友和宫廷结构，因此成为进攻面与防御资源。

优秀的计谋界面需要分别解释：是否有资格、准备得多好、还要多久、风险在哪里。把这些合成一个百分比，会令玩家无法判断应该招人、等待还是换目标。

## 借鉴与最小验证

做一个暗杀计谋、三类同谋、准备进度和曝光风险。允许招募目标的近臣，给玩家两个执行时点。

观察玩家是否会因目标即将出征、同谋可能失效或对手开始反制而提前行动。若唯一正确答案永远是等待最大成功率，就需要更真实的时间压力。
