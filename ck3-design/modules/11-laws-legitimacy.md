# 11 法律、合法性与暴政

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

决定统治者拥有多少正式权限，以及行使这些权限后能否继续被社会接受。提升制度权威 → 获得控制能力 → 支付政治代价 → 通过成果与仪式维护统治。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 权威法律 | 依政体限制战争、剥夺、继承指定等权力 | 更强控制通常需要相应制度条件并产生反对 |
| 继承法律 | 规定权力如何转交 | 当代治理与下一代稳定互相牵制 |
| 合法性 Legitimacy | 衡量统治权被认可的程度，并存在期待 | 身份越高，维护统治正当性的要求可能越高 |
| 暴政 Tyranny | 不被视为正当的统治行动带来集体政治代价 | 快速重分权力，还是保留长久服从 |
| 恐怖值 Dread | 通过恐惧抑制或改变部分人物行为 | 恐惧可以与憎恶并存，不等于认可 |
| 正当理由 | 宣称、罪行等可能让惩罚或剥夺合法化 | 先取得理由，还是直接承担代价 |
| 政体特有法律 | 行政、游牧、中国、日本等拥有不同权限与资源条件 | 不能用一套王权等级覆盖所有制度 |

合法性是 1.12 免费引入的基础机制；它与个人威望、宗族威望、好感、恐怖值不是同一个变量。部分官僚附庸还使用功绩等不同评价结构。[^1][^2]

## 关键决策与设计判断

设计上应区分“法律允许”“具备执行能力”和“社会认可”。同一项逮捕，可能合法但失败，也可能执行成功却引发更大反对。这种区分让政治不只是解锁按钮。

不能简单将低合法性解释成必然倒台，也不能将高恐怖值解释成绝对安全。具体结果依赖人物性格、派系资格和制度环境，结构上应保留多种维持统治的路径。

## 借鉴与最小验证

制作一次剥夺头衔行动，分别输入“有宣称／无宣称”和“强势／弱势统治者”。让玩家同时看见合法性判断、执行可能性与关系后果。

验收时要求四种局面不能得出完全一样的结果。若法律只提供全局加成，可先增加一个改变行动资格的条款。
