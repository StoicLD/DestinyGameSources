# 26 行政制与拜占庭

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

将“占有世袭土地”部分替换成“维持家族资产并竞争帝国公职”。经营宅邸 → 积累影响力和家族实力 → 争取任命 → 通过治理和政治竞争扩大权力 → 争夺更高职位。主要由 Roads to Power 提供可玩行政制。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 家族宅邸 Estate | 家族持续存在的资产载体 | 投资永久家底，还是优先争取当前职位 |
| 显赫家族竞争 | 家族地位影响政治能力 | 强化自己，或与其他家族合作 |
| 影响力 Influence | 官僚政治中的主要行动资源 | 支持家人、打击对手或调用国家能力 |
| 候选与任命 | 官职接替依候选评分和政治支持等规则 | 公职不应简单视为父传子的私人地产 |
| 总督能力 | 治理表现、经验和效率影响任职价值 | 取得职位之后仍需要有效治理 |
| 职位关联军队 | 一些军队与头衔相连，并可由中央协调 | 私人军力与国家职位资源分开 |
| 公私财政 | 现行版本用国库与金币区分部分公共和私人支出 | 权力增加不等于私人财富可以随意支取 |
| 国教与帝国政治 | 官方信仰、政治计谋、共治等进一步塑造竞争 | 宗教和家族策略都要适应中央制度 |
| 拜占庭内容 | 赛马、特殊宫廷角色与共治等提供地区表达 | 共通制度与特色内容相互配合 |

国库在后续 1.18 体系中扩展到行政制，不能认为所有现行行政机制都来自 2024 年首发版本。[^2]

## 关键决策与设计判断

最重要的变化是公职与家产分离。角色失去一省治理权后，家族仍可能依靠宅邸和人脉继续竞争；这使“失去土地”可以成为权力曲线的一部分。

政治对手争夺的是能影响公共资源的职位，因此职位自身需要有职责和权限。若官职只是收入等级，官僚玩法仍会退化成普通地产争夺。

## 借鉴与最小验证

做三个家族、两个总督职位、一座家族宅邸和一种影响力资源。每次任命有公开候选分数，任职者获得公款预算但不能直接把它当私产。

让玩家经历一次落选后继续游玩。验证经营家族是否仍有作用，以及好总督能否通过实际治理提高竞争力。
