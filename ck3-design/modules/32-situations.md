# 32 斗争、局势与丝绸之路

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

让地区历史环境拥有参与者、阶段和变化条件。玩家判断自己在局势中的身份 → 利用当前规则 → 通过实际行为推动阶段 → 争取有利结局。它连接多名统治者，超出单个人物事件的范围。[^1]

## 子机制：共通结构

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 参与资格 | 涉及者、介入者、无关者或特定群体有不同影响权限 | 是否进入地区政治、改变自身身份 |
| 地区与作用范围 | 决定哪些人物和地点受影响 | 玩家不必在场景中心才受其后果 |
| 阶段 | 阶段改变可用行动、费用、关系或其他环境效果 | 顺应当前规则，还是主动推动改变 |
| 推动条件 Catalysts | 战争、合作、治理和其他实际行动推动进程 | 行动的直接收益与地区长期变化 |
| 结束条件 | 某些局势可按不同路径结束，另一些持续循环 | 完成自己偏好的地区秩序 |
| 可视化 | 显示阶段、参与者和进度来源 | 让宏观变化可理解、可规划 |

这是设计层抽象。斗争、草原季节、灾害与中国王朝循环使用不同具体条件，不代表它们每一项都按完全相同的内部代码运行。

## 主要实例

| 系统 | 核心差异 | 主责 |
| --- | --- | --- |
| 伊比利亚斗争 | 机会、敌对、妥协、调解等循环阶段；支持不同长期结局 | 本页 |
| 伊朗间奏曲 | 867 起始的地区冲突，围绕哈里发权威的支持／反对及阶段终结 | 本页与 [25 氏族](25-core-governments.md) |
| 中国王朝循环 | 帝国政治运动、天命与稳定／动荡阶段互相推动 | [29 中国](29-china.md) |
| 草原季节 | 多年尺度的地区条件变化，推动肥力、迁移和统治行为 | [28 游牧](28-nomadic.md) |
| 自然灾害 | 预警、冲击、恢复与共同贡献 | [24 灾害](24-disasters.md) |
| 丝绸之路 | 地区状态与创新传播，使中国及沿线变化影响更远的世界 | 本页与 [16 革新](16-culture.md) |

伊比利亚与伊朗属于不同内容包；丝路现行机制来自 All Under Heaven。丝路有分区、枢纽与向西传播的革新，不能简化为玩家自由绘制商路并经营商品价格。[^1][^2]

## 关键决策与设计判断

这类系统把宏观背景变成可参与的规则变化。官方在介绍伊比利亚斗争时明确强调阶段提供新机会与约束；本页进一步将其概括为由集体行为推动的状态机。[^3]

主要风险是玩家为了凑阶段条件而进行不符合目标的行为。推动条件应尽量来自正常玩法，进度和结束条件也应在制定长期计划前可见。

## 借鉴与最小验证

用 4 个家族做“合作／紧张／冲突”三阶段。婚姻、背约、战争和让步推动变化；每阶段只改一项外交规则与一项军事规则。

检查其他角色的行为是否也能推动局势，以及同一行动在不同阶段是否产生不同取舍。无需加入一长串专用刷进度按钮。
