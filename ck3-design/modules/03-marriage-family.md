# 03 婚姻、生育与血缘

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

婚姻是把家庭、外交和未来权利绑定起来的长期安排。玩家寻找对象 → 比较接受条件与收益 → 建立婚姻和家族归属 → 通过生育与继承让结果延迟兑现。它同时涉及多方，而非只给两名角色增加好感。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 婚约与婚姻 | 未成年可订婚，成年后成婚；接受度由双方地位与条件共同影响 | 提前锁定政治机会，还是保留选择 |
| 父系／母系归属 | 通常决定婚生子女进入哪一方家族 | 好配偶未必能延续玩家自己的家族 |
| 婚姻联盟 | 合资格的亲属联姻可以建立统治者之间的联盟 | 当前军事支持与未来家族布局如何兼顾 |
| 生育与后代 | 生育受年龄、特质等影响；更多子女增加关系选项和继承备份 | 子女数量与分割继承的压力互相牵制 |
| 遗传 | 某些先天特质和外貌可以遗传；近亲组合存在负面风险 | 追求遗传优势与政治条件可能冲突 |
| 婚姻规范 | 配偶数量、离婚、血亲婚姻、私生子地位受信仰等规则影响 | 改变信仰也可能改变家庭安排 |
| 亲缘与宣称 | 子女、兄弟姐妹等关系影响继承资格与宣称传递 | 婚姻可能制造未来盟友，也可能制造争位者 |

上述是游戏中的关系与规则表达，不等同于对现实婚姻或遗传学的完整模拟。[^1]

## 关键决策与设计判断

婚姻的设计深度来自“多目标同时结算”：强国联姻、优秀能力、家族归属、继承机会与年龄条件很难全部最优。候选人筛选界面之所以关键，是因为没有可比较的信息，这类深度会退化成查表负担。

不要把“与继承人结婚”直接写成“获得对方领地”。还要看婚姻归属、继承资格、存活情况、继承次序及是否能够继续控制对应人物。

## 借鉴与最小验证

用 8 名角色和两个家族做一张婚姻候选表，只保留联盟价值、子女归属和继承资格三项。让下一次接班真实执行其后果。

如果玩家能说明自己为何放弃最强盟友、选择另一名配偶，说明多目标取舍成立。若只有一个候选永远占优，则候选设计不足。
