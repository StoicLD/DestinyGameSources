# 21 王室宫廷与宝物

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

把统治地位与家族历史转化为可以看见、维护、传承和争夺的空间与物品。投入宫廷资源 → 吸引人物和处理请愿 → 获得、展示与保存宝物 → 将其收益带入下一代。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 王室宫廷视图 | 让统治者、家人和要员进入同一可视空间 | 用空间和服饰表达关系与地位 |
| 朝会与请愿 | 接收不同人物诉求，选择处理结果 | 一项裁决可能使不同集团得失相反 |
| 显赫度与期待 | 宫廷投入、宝物等构成显赫基础，社会对不同统治者有期待 | 足够体面，还是追求额外地位 |
| 宫廷类型与语言 | 将文化、社交与宫廷收益相连 | 维持本地身份或参与更广泛的文化影响 |
| 宝物种类与装备 | 个人物品与宫廷展示物各有使用位置和效果 | 有限槽位决定哪些历史与能力被激活 |
| 委托与灵感 | 获得物品的过程可需要赞助、人物和阶段事件 | 对不确定品质追加投资 |
| 耐久、修复与重铸 | 物品持续存在有维护要求 | 保存象征性物件，还是投入更高价值资产 |
| 宝物宣称与争夺 | 物品拥有者、原主人、家族权利和战利品之间产生冲突 | 物品既是加成，也能成为战争和计谋目标 |

1.13 已将宫廷视图和宫廷宝物加入本体；朝会、显赫度等深层玩法仍依赖 Royal Court。不能把整个模块一概判作付费独占。[^2]

## 关键决策与设计判断

一个拥有来历的物品，能以很低的新增规则成本串起人物与家族记忆。祖父的战旗被敌人夺走，其价值不只来自属性，还来自已经发生的故事。

视觉应表达实际状态：服饰、陈列、人物位置与历史信息帮助玩家识别组织。若大量美术制作只提供静态背景，就难以支撑持续互动。

## 借鉴与最小验证

做一个二维宫廷界面和三件宝物，每件保存制作者、获得方式、前主人与传承历史。设计一次被夺走后的索回机会。

验证玩家是否在属性相近时因为物品经历而作出不同选择。先完成物件历史和选择，再考虑昂贵的 3D 宫廷。
