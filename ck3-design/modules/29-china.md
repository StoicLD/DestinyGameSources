# 29 中国、官僚与王朝循环

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

将家族经营、个人仕途与帝国兴衰连接起来。家族培养人才 → 经考试与治理取得功绩 → 进入文武官僚体系 → 参与预算和政治运动 → 维持王朝或在动荡中改变归属。主要内容来自已发布的 All Under Heaven。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 天朝 Celestial | 中国的官僚统治结构，拥有专门权威、任命与中央机制 | 家族目标与帝国职责的取舍 |
| 功绩型政体变体 | Meritocratic、Meritocratic Khanate 等复用功绩与部分官僚机制 | 不能把所有使用功绩的政体都视为同一帝国身份 |
| 功绩 Merit 与品级 | 评价任职资格和官僚发展，与影响力用途不同 | 提高真实资历，或通过政治支持影响竞争 |
| 科举活动 | 分层考试推动教育与晋升资格，也存在作弊风险 | 正常成长的时间成本与捷径风险 |
| 文武职业 | 军事和文官岗位在要求、资源与职责上有差异 | 不同能力应有不同上升通道 |
| 国库与薪俸 | 中央汇聚并分配公共资源，官员取得薪俸 | 维持军队、建设和官僚组织的预算比例 |
| 中央部门与共享权力 | 中央官职拥有具体权限，中书体系参与政治 | 皇帝的名义权力与官僚实际控制不同 |
| 家族志向与师徒 | 长期家族方向、教育和人脉支持个人发展 | 长期投资与眼前职位争夺 |
| 天命与政治运动 | 帝国统治评价、集团力量与政策方向相连 | 维护现状、推动扩张或发展、争取变局 |
| 王朝循环 | 发展、扩张、紧张、征服、分裂等阶段改变环境 | 在同一地图上经历不同的宏观解题条件 |
| 朝贡与恩宠 | 帝国外部关系提供区别于直接吞并的互动 | 用礼仪和义务交换保护、机会与资源 |

此处“天命”不是对现实历史规律的宣称，而是游戏的制度化表达。实际参与资格、任命细节和阶段推动条件较复杂，应分别查天朝、继承与局势页。[^1][^2]

## 周边官僚政体的区别

| 政体 | 主要分布或代表 | 独立设计内容 |
| --- | --- | --- |
| Celestial | 中国 | 天命、中央部院和王朝循环等帝国层结构 |
| Meritocratic | 朝鲜半岛及中国周边部分王国 | 复用宅邸、功绩、考试、国库与任命；功绩品级等条件有自身边界 |
| Meritocratic Khanate | 1066 的辽、1178 的金等 | 官僚体系与草原传统结合，保留劫掠、部分夷平、服从和从臣属招募兵种等机制 |

第三类尤其值得研究：它以一套官僚骨架组合部分草原规则，没有简单退回游牧政体。周边政体也可能出现象征君主与执政者分离；不能据此认定它们都自动具有中国的完整中央结构。[^3]

## 关键决策与设计判断

这套设计有三种时间尺度：个人准备考试与任职，家族累积长期优势，帝国在阶段间变化。若三者能相互影响，玩家就会遇到“个人正确但不利于帝国”的选择。

公共财政与政治运动给“大帝国已经成立以后玩什么”提供答案。其内容与工程成本也很高，不适合作为个人项目的首个完整模块。

## 借鉴与最小验证

先制作一个官职竞争原型：三名候选、两种资历、一个公共预算。再添加“稳定／紧张”两阶段，让灾后治理和派系行为共同推动阶段。

验证高分候选不是唯一优势来源，公共支出又能真实影响社会状态。不要先制作完整中国史数据库。
