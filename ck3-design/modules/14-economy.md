# 14 资源、财政与建设

[返回总览](../README.md) · [设计总纲](../00-framework.md) · [版本](../01-version-and-dlc.md) · [来源索引](../04-sources.md)

## 核心玩法

把有限资源投入不同回报周期，支持统治、战争和家族目标。获得收入 → 支付固定支出 → 选择建设或政治投资 → 扩大未来能力 → 保留应付危机的储备。[^1]

## 子机制

| 子机制 | 核心内容 | 玩家取舍 |
| --- | --- | --- |
| 金币 Gold | 流动资金，支撑建设、军费、雇佣、礼物和活动 | 长期投资与眼前流动性 |
| 威望与虔诚 | 分别服务大量世俗和宗教行动 | 无法只靠囤钱解决所有问题 |
| 名望／奉献等级 | 与可支出的威望、虔诚余额分开 | 保留地位门槛，同时允许消耗行动资源 |
| 宗族威望 Renown | 宗族层面的积累与传承资源 | 个人应急与全族长期利益 |
| 专属资源 | 影响力、行粮、牧群、易货货物等改变政体循环 | 政体差异进入生产和消费链 |
| 地产与建筑 | 城堡、城市、神殿等及其建筑线提供收入、防御或军事价值 | 投资产出、兵种支持还是生存能力 |
| 维护与债务 | 军队、宫廷和职位支出形成持续负担；负债带来约束 | 是否过早建立自己养不起的能力 |
| 国库 Treasury | 某些官僚政体区分公款与私人金币 | 投资公共治理还是家族私产 |
| 大工程 | 多角色可共同贡献的项目框架 | 共同收益、私人奖励和搭便车之间的取舍 |

建筑还受地形、革新、地产和政体条件约束。公共工程框架在 1.18 免费更新引入，其专属项目另看解锁条件。[^2]

## 关键决策与设计判断

多资源的价值在于分别限制不同活动。若所有资源都可按固定比例无限兑换，系统最终仍可能只剩一项最优赚钱活动。

名望等级与可消费余额分离，有助于避免“花掉威望后瞬间失去曾经建功的社会地位”。但文档必须区分两者，界面也应清楚显示收入、余额、累计等级和期望值各自含义。

## 借鉴与最小验证

只用金币、政治资本和家族声望三种资源；加入经济建筑、防御建筑、礼物三种支出。设计一次战争和一次接班，使储备和投资都可能有价值。

观察玩家是否会因预期危机改变预算。若最佳玩法始终是建同一条生产线，先改变风险和投资回收周期，暂不增加资源种类。
