# 16 蝴蝶效应案例：该改写什么，不该改写什么

[返回总览](../README.md) · [系统地图](../00-design-map.md) · [版本边界](../01-version-boundaries.md) · [来源索引](../02-sources.md)

## 核心内容

历史适应不是把所有异常归为“跳过事件”。下面用一组原创古代情景检验同一套规则：保留诉求、尊重当前事实、给出有限的合法后续。

HOI4 官方修补中的目标消失、路线替代与历史计划取消说明了这些类别的现实价值，但下表并非 HOI4 已自动实现的古代逻辑。[^1][^2]

## 十二种情景

| 玩家造成的变化 | 不合理处理 | 建议处理 | 必须读取的状态 |
| --- | --- | --- | --- |
| 提前收复原定讨伐目标 | 仍强制开战，或判错过任务 | 标为其他方式解决，承认真实成果 | 当前权属、争端目标 |
| 敌对边镇被第三方兼并 | 把宣战对象直接换成新主人 | 重评争端、关系、实力与备战 | 新旧政权、争端来源、条约 |
| 目标主动归附 | 继续敌对事件 | 转入接收、整编与统治安排 | 附属关系、原承诺 |
| 原定叛将提前死亡 | 同名替身出现并照旧叛乱 | 身份事件终止；结构性矛盾另找合格参与者 | 人物身份、组织与矛盾 |
| 朝廷已完成军制改革 | 再发同一改革奖励 | 标记已采用，转向普及或实施评估 | 制度版本、各军采用率 |
| 改良器械提前出现 | 到原定年份重复解锁 | 可展示领先成果，或转向扩散与竞争 | 知识、实物、生产与采用 |
| 粮道被毁，出征日期已到 | 凭空补满粮草并出兵 | 延期、缩军、改道、修复或放弃 | 库存、日耗、到货与道路 |
| 主将换任、命令仍在途 | 旧将令覆盖新将令 | 按授权、命令版本与接班规则处理 | 指挥关系、消息序列 |
| 使者途中争议地转手 | 原主人仍可割让他人土地 | 原提议失效或重谈 | 实际权属、提议绑定 |
| 灾害发生但玩家已充分准备 | 为保证历史损失强制粮尽 | 灾害影响保留，准备降低后果 | 地区暴露、库存与恢复能力 |
| 任务完成后领地又失去 | 重开原实例反复领取奖励 | 记录旧完成，新建新的危机实例 | 完成记录、丢失事件 |
| 政权灭亡后同名政权重建 | 数十年前的最后通牒突然生效 | 默认过期；仅合法继承的承诺可接续 | 实例期限、实体身份、继承关系 |

## 同一历史节点的四种合法终局

以“整顿边防”为例：

**战争完成。** 朝廷经备战与作战控制危险据点，记录战争成果和真实损失。

**外交完成。** 对方停止袭扰并建立有效约束，记录协议与履约责任，而不是虚构战场胜利。

**目标被替代。** 第三势力介入改变问题，旧章节结束，新章节处理新的威胁和关系。

**未解决而结束。** 财政、政治或条件变化使该轮行动终止，保留未解决压力，但不让同一事件无限弹出。

章节的“结束”不等于世界问题永远消失；世界问题再次出现时可以创建新实例，但重复奖励与事件文本都应识别此前历史。

## 何时可以动态换人

“需要当前负责粮运的官员回应”是职责槽，可以绑定现任负责人。“某名将因与某君主的特定经历而起兵”是身份内容，不能随意把下一位将领塞进去。

结构性矛盾可以产生新的同类事件，但应有新的参与者动机和事实依据。不要将“避免剧情中断”放在人物和政治逻辑之上。

## 历史模式的三个可配置档位

| 模式 | 时间与原路线权重 | 玩家改变后的处理 |
| --- | --- | --- |
| 历史倾向 | 较强，但只作用于有效候选 | 合法替代、延期或终止 |
| 因果沙盘 | 较弱，更多依赖当下利益 | 自然生成合格行动 |
| 剧情战役 | 特定关键事件可以预先固定 | 提前向玩家说明固定边界，其余尊重当前状态 |

这里是原创模式建议，不是 HOI4 的菜单说明。默认适合本项目的是前两种之间的可调权重；不需要第一版同时实现三套内容。

## 验证标准

不是“最后都回到史实”，而是：

1. 没有不存在的行动主体、越权领土转移或凭空物资。
2. 玩家能理解为什么这条内容出现、变化或结束。
3. 至少两种不同玩法能合理影响同一历史问题。
4. 相同世界状态与相同随机种子下，结果可复现。
5. 不会因等待、读档或对象重建反复获取同一奖励。
