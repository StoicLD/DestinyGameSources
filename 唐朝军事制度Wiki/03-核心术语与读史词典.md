> 适用范围：全唐；同名异义优先。
> 资料与编校基准：2026-09-17；证据等级和版本限制见凡例。

| 词 | 在军事材料中的常见含义 | 不宜直接等同于 |
|---|---|---|
| 府兵 | 依军府体系登记、简点并承担军役的兵员及其制度 | 人人终身在营的职业军人，或明代军户 |
| 府 | 折冲府、五府、都督府或军府衙署，要看全称 | 一个固定人数的战斗单位 |
| 卫 | 宿卫机构及其官属；部分卫与外府联系 | 一支随时满员出征的现代师 |
| 军 | 军队泛称、驻军建置、临时战役分军、番号 | 固定5000或固定10000人 |
| 镇、戍、守捉 | 地域防守建置、驻地及相应军职；层级随时地变化 | 全国通行的军—师—旅序列 |
| 营 | 营地、驻军、部伍或临时编组，须据上下文 | 现代营级人数 |
| 团、旅、队、火 | 不同文本中的军府或教战组织 | 可以跨所有材料直接套用的乘法表 |
| 番上 | 按番次上值；具体可有中央宿卫或地方轮值 | 一律远赴长安 |
| 征人、兵募 | 征行人员与临时征募组织；可能附带官府差发 | 完全自由进出的市场雇佣军 |
| 健儿 | 壮健军士的称呼，也用于长期边军语境 | 全唐唯一正式兵种名称 |
| 节度 | 调度统率的动作；也见于节度使职名 | 看到二字就认定藩镇制度已成熟 |
| 牙、衙 | 主帅军府、牙门、牙兵相关用字 | 所有时候严格分开的两个制度 |
| 牙兵、牙军 | 依附帅府的亲近、警卫或精锐军队，部分形成世袭集团 | 全镇军队，也不必一律私人奴兵 |
| 押衙、押牙 | 军府差遣及将校职名，用法与职掌变化很大 | 固定人数的连长 |
| 兵马使 | 统率某军、某部、某种兵马的使职 | 全唐固定品级和固定兵额的官 |
| 检校 | 加衔或任职语境须具体判断，晚唐常见荣衔化 | 一律实际主持该中央衙署 |
| 留后 | 长官未至或更代时主持本镇的安排 | 已获得法定世袭权的储君 |
| 粮赐、衣赐、优复 | 粮食、衣物或折支给付，及差役赋税优惠 | 统一按月支付的纯现金工资 |
| 露布 | 公开报告重大军事胜利的文书 | 可不加辨析采用的精确战果统计 |

上表解释据六典、律疏、百官志、兵志及田氏、淮西等具体事例综合整理。名词在史料中的实际指向优先于本表概括。[^D05][^L16][^N49][^N50][^J141][^Z240]

## 三个特别容易误读的句法
“以某官为某道行军总管”：前者常是人物本官，后者交代此次统兵任务。“授某将军，充某兵马使”：授官和实职差遣可以并列存在；不能删除后半句只凭将军高低解释兵权。“军中推为留后，朝廷因授节度使”：事实掌权与朝廷认可有先后关系，既非完整中央选派，也非完全不需要中央名器。[^Z193][^J141]

## 读史时怎样拆一条记录
先找动词：谁“奏”、谁“署”、谁“诏”、谁“充”、谁“将”、谁“给”。再看宾语是品秩、官职、兵众、财物还是辖地。最后查该人物是否带原有旧部、是否取得本地军众支持。这样比仅做一张官名升降表更接近实际军事权力。有关官阶与职掌详见 [武官与军事相关职掌总表](70-武官权力职责总表.md)、[官阶、职事、使职与易混名号](72-官阶职事使职与易混名号.md)。
