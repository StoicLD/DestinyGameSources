## 为什么建立这个页面
“详细”不等于把空缺全部填满。人数、官品、时间、来源、单位和修史语言一旦混淆，越大的表格越容易产生系统性错误。本页记录本次研究实际遇到的冲突，并规定各专题和十四问怎样处理。

## 校核事项
| 问题 | 文献差异或风险 | 本库处理 |
|---|---|---|
| **府兵总府数** | 《唐六典》相关记录594，《新唐书》百官志633、兵志634，另有后世概数。 | 分别记录出处、时段和统计对象；不选一个数字解释三百年。[^D05][^N49][^N50] |
| **团额与基层层次** | 常见300人团说，与律疏引令旅、校尉领队关系可推出200人的层次不一致。 | 保留并列制度材料；不强行改队额或府额使之整除。[^N49][^N50][^L16] |
| **彍骑之团** | 兵志记彍骑团50、火10，与军府团额不相同。 | 同名组织单位分制度、兵种与时点，不混接。[^N50] |
| **军镇的军、守捉、镇** | 不同地区、阶段的上下级与机动编组不能只凭名称固定。 | 用同地同时的文书和机构关系确认；论文引文未直接校原件。[^D05][^A05] |
| **上将军的时间** | 十六卫上将军为786年的制度增置层。 | 不写入贞观朝常设官表。[^N49] |
| **同名校尉的品秩** | 五府与外折冲府校尉、旅帅、队正副不同品。 | 表内分栏，不跨机构抄品秩。[^N49] |
| **中府兵曹品秩** | 本次《新唐书》录文为正九品下，与用户官职库相关表项正九品上有差异。 | 引用本次实际所读版本，标出冲突；不擅改用户仓库或伪称完成版本裁决。[^N49][^REPO] |
| **张茂和的卫官衔** | 裴度奏用张茂和相关事，《通鉴》卷240记右神武将军，《旧唐书》卷141有左武卫将军称。 | 并列为史源称衔差异；不合成两个必定同时在身的官。[^J141][^Z240] |
| **年龄建议与生效** | 25—50岁调整在兵志有未克行限制。 | 不将建议或记载中的方案当全国已执行法。[^N50] |
| **737长住边军政策** | 招情愿长住者并加给优复，不等于该年以后所有征发停止。 | 政策原文与实际持续征调分开。[^D05][^Z228] |
| **749停上下鱼书** | 有关旧府兵运行、登记手续的变化。 | 不解释为同日全国所有军府名称和人员全部消灭。[^N50] |
| **十人六马** | “六驮马”属于共享运输规范，且有用其他畜类替代的条件。 | 不能计算为唐军骑兵占60%。[^D05] |
| **个人口粮携行数** | 兵志有出征资装所带麦饭、米等数量。 | 携行定额不等于每日食量；保留原单位和出征语境。[^N50] |
| **甲名录文** | 鸟／乌、阜／皂等网络字形与通行写法有异。 | 只作类别阅读，正式引用先校版本；不静默更改引文后声称忠实原文。[^D16] |
| **兵书二万人方案** | 7×2800＋400在文本中可核算，不能证明所有实战采用。 | 用于说明组织思想，禁止当全唐常备满编表。[^T148] |
| **香积寺十五万与号二十万** | 原叙数与声称规模不同，尚有来源和非接战人员问题。 | 分别保存，不产生一个所谓精确到兵数。[^Z220] |
| **白江口战船四百** | 史载焚舟数，未同日本和半岛史源独立对勘。 | 标成该书记录，不作经过确认的精确舰队损失。[^Z201] |
| **大非川敌兵二十万、四十万** | 史载大军与归因叙事，未经多源兵籍核准。 | 不用来证明固定兵力比或计算指挥效率。[^Z201] |
| **魏博牙军五千／一万** | 不同书的初选牙军叙数不同。 | 保留来源与叙述时点，不把其一覆盖所有年代。[^J141][^N210][^Z265] |
| **八千家不是八千兵** | 906年杀戮以家计且包括婴孺。 | 不混人数、户数、家数；不淡化军人家属受害。[^Z265] |
| **和籴65%的估算** | 现代论文利用个案和假设作比例推算。 | 不是直接取得的全国军粮统计；不得删除假设后作结论。[^A06] |
| **屯田亩与顷** | 食货志相关数量和劳作资料按其原单位记录，部分录文另有校记。 | 不把每顷产量移作每亩，不套现代公顷换算生成伪精确产量。[^N53] |
| **刘晏转运成绩** | 褒扬性“无升斗溺”等语言不能当现代损失率账册。 | 记录改革组织方式，谨慎对待绝对化绩效语言。[^N53] |
| **监军是否全为宦官** | 684年魏元忠以殿中侍御史监军；中晚唐宦官监军是另一层发展。 | 监军与宦官不可互相定义。[^Z203][^Z240] |
| **撤监阵是否撤所有监军** | 817年裴度奏请与李愬中军仍有监军的记录并存。 | 区分监阵中使、监军及不同行营安排。[^Z240] |
| **全唐工资和俘获分成** | 已核材料不构成跨全唐统一月饷、抽成及战利品分配表。 | 不补无出处比例；按兵种、军队、战役、给物和时期分例。[^D05][^Z193][^Z220][^Z228][^Z240] |
| **海东士卒奏议** | 664年不满见刘仁轨转述，属于有劝谏目的的奏议。 | 可证存在相关申诉，不当全国匿名统计调查。[^Z201] |
| **《唐代军事财政与礼制》中译版年** | 网络书目存在不同年份线索。 | 仅列作者、译者、出版社与ISBN；本次不裁定版年，未读正文不用于论证。[^B05] |

## 常见的四种伪精确
一是把不同时代数字相加；二是把文学与政治宣传当点名册；三是用一种士兵、一条运输路线、一场战争的成本套全部军队；四是将规范写成百分之百执行。本文不提供没有材料支撑的现代单位转换、年均军费占比、单兵杀伤率或普遍日行速度。

## 建议的争议记录模板
```text
命题：
来源甲：书名／卷／原称／数量／日期或语境
来源乙：书名／卷／原称／数量／日期或语境
冲突性质：版本／时期／统计口径／制度层次／解释不同
当前处理：并列／限定适用／暂不采用
还需核对：具体点校本、出土原件、同年军簿等
```

本库尚未完成所有传世版本与原始文书的校勘；因此这里既是已做的防错工作，也是研究边界说明，不把“已经发现争议”冒称“已经解决争议”。
