## 阅读顺序
首次建立认识，可按“14兵源 → 2编制 → 10职掌 → 1指挥 → 13训练 → 3装备 → 4行军 → 5后勤 → 11作战”阅读；再接“6任免 → 7待遇 → 9依附 → 8藩镇 → 12禁军”。编号仍保持用户原问题次序，不因建议阅读顺序而重排。
