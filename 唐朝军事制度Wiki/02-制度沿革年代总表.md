# 制度沿革年代总表

[首页](README.md) · [专题索引](04-主题与问题索引.md) · [十四问](后续总结/README.md) · [争议校核](81-数字异文与争议校核.md)

> 适用范围：618—907年；只列已落实或标明阶段的节点。
> 资料与编校基准：2026-09-17；证据等级和版本限制见凡例。

以下是阅读坐标，不是声称某天全国同时换制。“制度阶段”允许重叠；未确认精确日期的转变不强填年份。

| 年代 | 制度或事件 | 军事意义与限制 | 依据 |
|---|---|---|---|
| 武德时期（618—626） | 创业军、元从、军府和诸卫并存 | 国家军制在战争中整合；不能把后出的开元官表回填武德 | 兵志[^N50] |
| 629—630 | 李靖等分道讨东突厥，诸路受其节度 | 本官与行军差遣分开；“节度”作为统率动词不等于后来常设节度使 | 通鉴卷193[^Z193] |
| 636，贞观十年 | 改称折冲都尉、果毅都尉的制度节点 | 早期军府官名须随年代辨认 | 兵志、百官志[^N49][^N50] |
| 662，龙朔二年 | 兵志记北衙羽林建号 | 北衙逐步形成自身组织，不能理解为十六卫又添一个卫 | 兵志[^N50] |
| 663—664 | 白江口水陆协同、海东军役奏议与轮替争论 | 说明海运、常驻、军赏、家庭负担在安史前已经互相制约 | 通鉴卷201[^Z201] |
| 670 | 大非川败战与将帅问责 | 辎重安排、军令执行与副将关系不能分离 | 通鉴卷201[^Z201] |
| 684 | 扬州战事，魏元忠以殿中侍御史监军 | 监军并非天然专属宦官，文职人员可深度参与军事决策 | 通鉴卷203[^Z203] |
| 垂拱时期（685—688） | 百官志追记府额上1200、中1000、下800 | 这组兵额有时代限定，不能称618—907不变定额 | 百官志[^N49] |
| 691，天授二年 | 司阶、中候、司戈、执戟设置节点 | 属卫官增设及等级体系，不等于新建四级野战编制 | 百官志[^N49] |
| 711，景云二年 | 河西节度使的重要建号节点 | 节度职权在边防实践中渐成，不能把所有前身一刀切排除 | 兵志[^N50] |
| 713前后 | 调整府兵服役年龄的议论 | 兵志所记25—50岁方案有“不克行”限制，不列为有效通行制度 | 兵志[^N50] |
| 723—725 | 长从宿卫、彍骑及轮番安排 | 解决京师宿卫来源问题，与边军长住化并非同一改革 | 兵志[^N50] |
| 737，开元二十五年 | 招情愿丁壮长住边军，给优复、田宅等 | 长征健儿的重要规范；并非全国一切征发当天停止 | 六典卷5[^D05] |
| 749，天宝八载 | 折冲府停上下鱼书 | 反映兵籍、交替失实与旧府兵运行衰退；非所有折冲官同时消失 | 兵志[^N50] |
| 755—763 | 安史战争 | 大规模联合动员、中央与地方重组；前期旧制与新使职同场出现 | 兵志、通鉴[^N50][^Z220] |
| 757，至德二载 | 神武军恢复设置；殿前射生扩充 | 北衙持续改组，不应用一张“六军表”覆盖每年 | 百官志、通鉴[^N49][^Z220] |
| 763以后 | 河北降将获授藩镇，神策进入禁军核心 | 地方军事财政与中央近军同时发展，不是单向“中央消失” | 兵志、田氏传[^N50][^J141] |
| 783—784 | 泾原兵变、奉天危机及收复京师时期 | 揭示出征待遇、京师兵籍、宿将和中使关系；本库卷228战例只详783初段 | 通鉴卷228[^Z228] |
| 786，贞元二年 | 十六卫增上将军；神策左右组织相关设置 | 后出官表中的上将军不能前移到贞观 | 百官志、兵志[^N49][^N50] |
| 798，贞元十四年 | 神策统军设置节点 | 不可与护军中尉的沿革混为一个日期 | 百官志[^N49] |
| 812，元和七年 | 魏博拥立田兴、获朝廷授节赐名弘正 | 兵众拥立可以通向归顺，并非只能通向叛乱 | 旧唐书卷141[^J141] |
| 817，元和十二年 | 平淮西，军功与伤亡善后诏令 | 联军协调、训练、降将任用、战后给赐的实践标本 | 通鉴卷240[^Z240] |
| 821—822 | 田弘正被杀、田布失去军众支持 | 朝廷授官、旧部、人情和军粮缺一不可；血缘与忠君都不能自动换来服从 | 旧唐书卷141[^J141] |
| 829，大和三年 | 魏博杀史宪诚、拥何进滔 | 担忧调镇、割州及利益变化可触发集团行动 | 新唐书卷210[^N210] |
| 870，咸通十一年 | 魏博因减粮帛传言等发生军变 | 待遇预期与军人政治的联结，不能只看实际已发金额 | 新唐书卷210[^N210] |
| 888，文德元年 | 乐彦祯、乐从训集团失败 | 新建“子将”与既有军众的竞争，不只是将帅对皇帝 | 新唐书卷210[^N210] |
| 904—906 | 中央君权遭强镇控制，地区军府扩张 | 保留唐官名不等于皇帝仍掌握实际军队 | 通鉴卷265[^Z265] |
| 906，天祐三年 | 罗绍威借汴军诛魏博牙军，继有地方军反抗 | 摧毁内部制衡可能以依附外部强权为代价 | 通鉴卷265[^Z265] |
| 907 | 唐朝终结 | 本库下限；五代只作为制度延续问题，不据五代兵制倒填全唐 | 本库研究范围 |

## 两项阅读提醒
“五府—折冲府—军镇—藩镇”不是四个按顺序替换的全国军制名词。五府属于特定宿卫体系，其他名词涉及不同的编管和地域层面。类似地，募兵先于749存在，军府消失也不能用一个全国同步、无残存的日期表示。[^D05][^N49][^N50]

本表只采用核读材料能承载的精度。龙武军从早期名称到稳定编制、神策中尉历次设置与废复等更细日期，仍应结合专门禁军史与纪传逐条追索，见 [覆盖范围与待考问题](82-覆盖范围与待考问题.md)。
